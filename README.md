# 🐣 OpenClaw Pet - Telegram Mini App

**Canlı Demo:** https://openclawpet.netlify.app/

## 🎮 Özellikler

### 5 Benzersiz Hayvan
- 🐧 **Penguen** - Cool komedyen
- 🐱 **Kedi** - Trip atan, zamklı bakışlı  
- 🐕 **Köpek** - Alarm kuran, enerjik
- 🐠 **Balık** - Sakin filozof
- 🐥 **Civciv** - Hipperaktif, meraklı

### Çalışan Mekanikler
- ✅ 3 Stat (Hunger, Happy, Energy)
- ✅ 3 Aksiyon (Feed, Play, Sleep)
- ✅ Otomatik kaydetme (localStorage)
- ✅ Gerçek zamanlı stat düşüşü
- ✅ Uzak kalma cezası (6h+ = pet özler)
- ✅ Her hayvanın farklı diyalogları
- ✅ Kritik durumda görsel uyarılar

### Proaktif Bildirimler (Cron Job)
- ⏰ **Her 6 saat:** Açlık kontrolü
- ⏰ **20:00:** "Seni özledim" (24h giriş yoksa)
- ⏰ **21:30:** Streak uyarısı

## 🚀 Kullanım

1. Telegram'da botu aç
2. "🐣 Open Pet" butonuna tıkla
3. Yumurtaya 5 kez dokun
4. Rastgele pet çıkar
5. Bakım yap, seviye atla!

## 🛠️ Teknoloji

- Frontend: HTML5 + Vanilla JS
- Hosting: Netlify
- Bildirimler: OpenClaw Cron
- Storage: LocalStorage + Telegram Cloud
